# Module_3_Secure_Coding

# Cryptography Assignment

This project demonstrates three basic cryptography concepts using Python.

## SHA-Hash
The SHA-256 program takes a message from the user and generates a SHA-256 hash. It also compares hashes to verify whether the message has been changed.

## Caesar
The Caesar cipher program encrypts a message by shifting each letter by a chosen number. It can also decrypt the encrypted message back to the original text.

## Digital Signature
The digital signature program creates an RSA private and public key pair. The private key is used to sign a message, and the public key is used to verify the signature.

These programs demonstrate hashing, encryption and decryption, and the use of public/private key pairs for digital signatures.
